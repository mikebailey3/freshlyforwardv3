What changed this round (measured, not guessed)

  • Every card/path/ring coordinate was measured from the reference's own hero-cluster bounding box (treated as its own 0-100% coordinate space) -- see the header comment in HeroCareerPath.tsx.
  • FreshFit moved from x=52% to x=40% (center-left of the cluster, matching the reference) instead of sitting isolated at the far right.
  • Path rebuilt as a 4-point winding curve (person → past the ring → a mid-right node → destination) with 2 visible milestone dots, restrained-but-obvious glow, and a destination marker -- not a single thin arc.
  • Figure's SVG scale grew from 0.13 to 0.22 -- now reads immediately as a person, not an icon-sized mark.
  • Card count grew from 3 to 7, matching the reference's density: Top Opportunity, Career Direction, Search Readiness, Skill Gap, Goal Progress, Applications, Strategist Support -- each at the reference's own layout slot. 2 (Top Opportunity, Applications) stay full-size as primary; the other 5 use a smaller/quieter treatment so it reads as layered, not 7 equally-loud widgets.
  • Two reference slots got truthful substitutions instead of literal copies: "Career Vault — 23 Assets" → Career Direction (Career Vault is still Coming Soon in this product); the named/photo'd "Monica is online" strategist → a generic icon avatar (matching this codebase's existing anti-fabrication convention).
  • Tablet got its own denser pass: bigger ring (200px), 3 cards instead of 2, tightened container height to cut dead space. Fixed a bug along the way where the walking figure was rendering hidden behind a card.
  • Mobile is unchanged this round -- round 4 feedback called it "better," and this round's requested changes were desktop/tablet only.
